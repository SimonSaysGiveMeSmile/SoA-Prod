# SoA-Prod

Combined repository for the Son-of-Anton product:

- `desktop/` — Son-of-Anton desktop app (Electron). Merged from `son-of-anton-public` with full history via `git subtree`.
- `mobile/` — Son-of-Anton mobile web client. Merged from `son-of-anton-mobile` with full history via `git subtree`.

Each subtree retains its original commit history. See individual READMEs inside each directory for build and run instructions.
